# Project rules

This is a free and open-source software (FOSS) project. Its canonical repository
is https://github.com/memento-knowledge/mkonnect.

## Public quality standard

Treat every contribution as publicly reviewable work. Maintain high standards
of software architecture, code readability, security, and consistency. Follow
established project conventions, keep designs clear and maintainable, and verify
changes with appropriate checks before claiming completion. Review code,
documentation, examples, and other contributed artifacts with the same care.

## Customer confidentiality

Never include explicit or indirect information about customers in repository
content or public communications. A reader must not be able to identify or infer
who any customer is, including by combining seemingly harmless details.

This applies to code, comments, tests, fixtures, examples, configuration, logs,
screenshots, documentation, commit messages, pull requests, issues, and replies.
Exclude customer names, domains, identifiers, infrastructure details, usage
patterns, and distinctive scenarios that could reveal a customer relationship.
Use independently invented, generic examples and synthetic data; merely replacing
a name is insufficient when the remaining context could identify a customer.

Before contributing content, review it for both direct disclosure and inference
risk. If a problem cannot be described without exposing customer information,
keep that context out of the public repository and public discussion.

## Public issues

Repository issues primarily serve external users and customers. Any issue or
reply authored by maintainers must meet the same quality and confidentiality
standards above. Write clear, generally applicable descriptions and use minimal,
synthetic reproductions without revealing the source customer or private context.
